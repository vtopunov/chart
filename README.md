Вывод графиков (подобно https://github.com/vtopunov/graphic.git)


Цели проекта:

1. Автономность и стабильность

- Всё собирается из исходных кодов
- 3rdparty содержит копию исходных кодов и архивы репозиториев https://github.com/vtopunov/3rdparty.git 
Расчитываю на то, что 3rdparty репозиторий будет удален или изменен в худшую сторону.

2. Простота и прозрачность

- В самом последнем стандарте С++ беру только то, что упрощает код и делает его похожим на Си (Не платить за многословность)
- Минимум слоёв, 3rdparty решает только одну задачу и делает это хорошо (Unix way)
- Без boost, Qt и других многоцелевых либ (Unix way без unix)
- Без исключений и другой сложной системы обработки ошибок (Достаточно true-false и крашдампа) 
- Без rtti

3. Эффективность

- Не платить за то, что не используешь. Compile time features
